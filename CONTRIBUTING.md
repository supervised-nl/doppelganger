# Contributing

The maintainer is Jeroen Gijselaar.

Open questions and bugs as GitHub issues at https://github.com/supervised-nl/doppelganger/issues.

## Ask a spec question

When you want to know what the spec requires or allows, use the spec question issue template.

## Report a site bug

When a page on https://doppelganger.md is wrong, broken, or missing, use the site bug issue template.

## Send a pull request

Keep the change small. Do not rename `DOPPELGANGER.md`. Do not change the domain.

The site lives in `docs/`. See [README.md](README.md) to preview the site and to check the mirrored spec files.
