Load Paste it, attach it, or @ it.

The same three steps in every tool. The file SHOULD stay at or under 4600 characters. Voice fingerprint SHOULD hold at least 20 percent of the file. If a box has a character cap, drop Hard bans, then Tone rules, then two Voice fingerprint samples, then Limits. Keep Meta and the remaining samples. Attach the full file where the tool allows it.

To load a DOPPELGÄNGER.md voice file, put the file in the chat and tell the model to write as that voice. There is no installer, no account, and no hosted loader. If a chat tool will not fetch the .md URL, download the file and upload it, or paste the text.

Download the example file

Tool 1

ChatGPT

  1. Create a Project

    A project keeps the file attached to every chat inside it.

  2. Add the file to Sources

    Use Add files and upload DOPPELGANGER.md.

  3. Point the instructions at it

    Write: write user-facing copy in the voice of the attached DOPPELGANGER.md, follow Hard bans and Limits, do not invent facts.

Custom instructions cap at 1,500 characters on Free and Go, and at 5,000 on Plus, Pro, Business, Enterprise, and Education, checked on 2026-09-19 against OpenAI Help: ChatGPT custom instructions. The example file is 4356 characters, so it fits the 5,000 cap. On a 1,500 cap, drop Hard bans, then Tone rules, then two Voice fingerprint samples, then Limits. Keep Meta and the remaining samples. Attach the full file where the tool allows it.

Tool 2

Claude

  1. Open a Project

    Upload DOPPELGANGER.md to project knowledge.

  2. Set the project instructions

    Tell Claude to write from that file and to obey Hard bans and Limits.

In Claude Code, attach the file with @DOPPELGANGER.md.

Tool 3

Gemini

  1. Create a Gem, or open a chat

    Either works. A Gem keeps the file across sessions.

  2. Attach or paste the file

    Add DOPPELGANGER.md as a knowledge file, or paste it at the top of the first message.

  3. Name the rules

    Tell Gemini to follow the file, including Hard bans and Limits.

In Gemini CLI, attach the file with @DOPPELGANGER.md.

Tool 4

Cursor

  1. Keep the file in the repo

    Project root, or the workspace you are writing from.

  2. Attach it in chat

    Type @DOPPELGANGER.md.

If you also keep an AGENTS.md, point it at the voice file for user-facing copy.

Tool 5

Paste anywhere

  1. Copy the full file

    All of it, including Meta and the marker.

  2. Paste it at the top of a new chat

    Before anything else.

  3. Add one line

    Write as this voice. Follow Hard bans and Limits.

If the composer turns a long paste into an attachment, leave it attached. That is still a load.
