FAQ Aliases, neighbours, and limits.

What the file is, what it is not, and why there is nothing to sign up for.

DOPPELGÄNGER.md is the open Markdown voice file for tone of voice. People also call it a brand voice file, a voice map, or write-like-me instructions. It sits next to AGENTS.md, which tells a coding agent how to work in a repo, and it stays out of visual identity, which is what BRAND.md covers.

Questions

How is this different from AGENTS.md?

AGENTS.md tells a coding agent how to work in a repo. DOPPELGÄNGER.md tells any model how you write. Keep both, and point AGENTS.md at the voice file when the agent writes user-facing copy.

How is this different from BRAND.md?

BRAND.md and Brand Context Protocol cover strategy, voice, and visual identity. If you want a brand voice for writing only, use this file. DOPPELGÄNGER.md is voice only. No logo rules, no palette, no layout.

Is this a tone of voice (ToV) file?

Yes. DOPPELGÄNGER.md is the open Markdown voice file for tone of voice. Load it with paste, attach, or @DOPPELGANGER.md.

Is this a voice map, voicemap, or voice.md?

Same job. Prefer the filename DOPPELGANGER.md and this spec so tools know where to look.

Custom instructions, or write like me?

Put the file in the chat. Paste it, attach it, or @ it. There is no hosted loader. See Load.

Why is there no hosted loader?

A hosted loader becomes an account, an API, and lock-in. The convention is the file. Paste it, attach it, or @ it.

Can the file hold secrets?

No. The spec forbids keys, passwords, tokens, and unpublished personal data. It also forbids invented facts, metrics, and clients.

How do I make the file accurate?
  • Prefer real writing you already sent or published, such as email, posts, your site, and blogs, over AI drafts.
  • Scrub secrets and private third-party details before pasting samples.
  • Keep three to seven short samples across registers. Quality beats volume.
  • When replies stop sounding like you, refresh the samples and bump Meta version and updated.
  • Re-run on a schedule only if that helps you. The file does not expire.
Person or company?

Meta kind is person or organization. The sections are the same. An organization file speaks as the company.

Which language?

Spec 0.1 is English only. Meta language is a BCP 47 tag. Use en.

What is the license?

The spec, the example, and this site are public domain under CC0 1.0. Your own file can use another license. Name it in Meta.

Where is the canonical site?

https://doppelganger.md is live. The source lives at github.com/supervised-nl/doppelganger.
